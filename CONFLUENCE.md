# BigQuery Metadata Manager - Описание сервиса

## 📋 Обзор

**BigQuery Metadata Manager** — веб-приложение для управления метаданными BigQuery таблиц и колонок. Сервис предоставляет удобный интерфейс для просмотра, редактирования и автоматической генерации описаний таблиц и колонок с использованием OpenAI API.

**URL:** https://tables-and-columns-description-web-gccuajx7eq-ew.a.run.app

**Проект:** guns-and-gangs  
**Регион:** europe-west1  
**Платформа:** Google Cloud Run

---

## 🎯 Назначение

Сервис решает следующие задачи:

1. **Централизованное хранение метаданных** — все описания таблиц и колонок хранятся в BigQuery таблицах метаданных
2. **Визуальный просмотр и редактирование** — удобный веб-интерфейс для работы с метаданными
3. **Автоматическая генерация описаний** — использование OpenAI для создания описаний на основе структуры таблиц и sample данных
4. **Синхронизация с BigQuery schema** — автоматическое обновление описаний в BigQuery metadata

## 🏗️ Архитектура

### Компоненты системы

1. **Web UI (Cloud Run Service)**
   - FastAPI приложение
   - Веб-интерфейс для пользователей
   - Google OAuth аутентификация
   - API для генерации описаний через OpenAI

2. **Metadata Generator (Cloud Run Job)**
   - Фоновый процесс для массовой генерации метаданных
   - Автоматический запуск по расписанию (Cloud Scheduler)
   - Генерация описаний для всех таблиц проекта

3. **Хранилище метаданных**
   - `analytics_280581623.table_descriptions` — описания таблиц
   - `analytics_280581623.column_descriptions` — описания колонок

### Технологический стек

- **Backend:** Python 3.11, FastAPI, Uvicorn
- **Frontend:** Jinja2 templates, Vanilla JavaScript, CSS
- **База данных:** Google BigQuery
- **Аутентификация:** Google OAuth 2.0 (authlib)
- **AI:** OpenAI API (GPT-4o-mini)
- **Контейнеризация:** Docker
- **CI/CD:** Google Cloud Build
- **Хостинг:** Google Cloud Run

## 🔐 Аутентификация и доступ

### Метод аутентификации

Сервис использует **Google OAuth 2.0** для аутентификации пользователей.

### Требования к доступу

- **Домен:** Доступ ограничен пользователям домена `oneupgames.gg`

### Процесс входа

1. Пользователь открывает URL сервиса
2. Нажимает кнопку "🔐 Войти через Google"

4. После успешной авторизации получает доступ к интерфейсу

## 📊 Функциональность

### Основные возможности

#### 1. Просмотр метаданных

- **Иерархический вид:** Датасеты отображаются в свернутом виде, при клике разворачиваются таблицы
- **Поиск:** Фильтрация таблиц и колонок по названию
- **Индикаторы:** Визуальные маркеры для таблиц без описаний

#### 2. Редактирование описаний

- **Таблицы:** Редактирование описания таблицы с сохранением в BigQuery
- **Колонки:** Редактирование описаний отдельных колонок
- **Автосохранение:** Изменения автоматически синхронизируются с BigQuery schema

#### 3. Генерация через AI

- **Генерация описания таблицы:**
  - Получение sample данных через `TABLESAMPLE SYSTEM (2 PERCENT)`
  - Формирование промпта с информацией о таблице и данными
  - Генерация описания через OpenAI GPT-4o-mini
  - Автоматическое сохранение результата

- **Генерация описания колонки:**
  - Получение sample значений колонки
  - Генерация описания с учетом типа данных и примеров значений
  - Автоматическое сохранение

- **Информация о процессе:** Модальное окно показывает детали процесса генерации перед запуском
- **Отслеживание стоимости:** Отображение стоимости каждого запроса к OpenAI

#### 4. Безопасность

- **Маскирование чувствительных данных:** Имена таблиц и колонок с чувствительными паттернами маскируются перед отправкой в OpenAI
- **Параметризованные запросы:** Все SQL запросы используют параметризацию для предотвращения SQL injection
- **Валидация входных данных:** Проверка имен таблиц и колонок перед обработкой

## 🔌 API Endpoints

### Веб-интерфейс

- `GET /` — Главная страница со списком таблиц (требует аутентификации)
- `GET /table/{dataset}/{table_name}` — Страница деталей таблицы с колонками (требует аутентификации)
- `GET /login` — Инициация OAuth логина
- `GET /auth/callback` — OAuth callback обработчик
- `GET /logout` — Выход из системы

### API для редактирования

- `POST /api/table/{dataset}/{table_name}/description` — Обновление описания таблицы
- `POST /api/table/{dataset}/{table_name}/column/{column_name}/description` — Обновление описания колонки

### API для генерации

- `POST /api/table/{dataset}/{table_name}/generate-description` — Генерация описания таблицы через AI
- `POST /api/table/{dataset}/{table_name}/column/{column_name}/generate-description` — Генерация описания колонки через AI

**Все API endpoints требуют аутентификации через OAuth.**

## 🚀 Развертывание

### Автоматическое развертывание

Развертывание выполняется через **Google Cloud Build** при пуше в GitLab репозиторий.

**Конфигурация:** `cloudbuild-web.yaml`

### Процесс развертывания

1. Сборка Docker образа (`Dockerfile.web`)
2. Загрузка образа в Container Registry
3. Развертывание Cloud Run Service
4. Настройка переменных окружения и secrets

### Переменные окружения

- `GOOGLE_CLIENT_ID` — OAuth Client ID
- `GOOGLE_CLIENT_SECRET` — OAuth Client Secret
- `REDIRECT_URI` — OAuth redirect URI
- `SECRET_KEY` — Секретный ключ для сессий
- `OPENAI_API_KEY` — API ключ OpenAI (из Secret Manager)
- `OPENAI_MODEL` — Модель OpenAI (по умолчанию: gpt-4o-mini)

### Secrets

- `OPENAI_API_KEY` — хранится в Google Secret Manager (`analytics_table_desc_ai_creator`)

## 🛡️ Безопасность

### Реализованные меры

1. **SQL Injection Prevention**
   - Все запросы используют параметризацию через `ScalarQueryParameter`
   - Валидация имен таблиц и колонок

2. **Защита чувствительных данных**
   - Маскирование имен таблиц/колонок с чувствительными паттернами перед отправкой в OpenAI
   - Паттерны: pii, personal, ssn, password, credit card, payment, secret, token, auth, credential

3. **Аутентификация**
   - Google OAuth 2.0
   - Ограничение доступа по домену (oneupgames.gg)
   - Сессии с защищенным ключом

4. **Secrets Management**
   - OpenAI API ключ хранится в Google Secret Manager
   - Не хранится в коде или переменных окружения напрямую
